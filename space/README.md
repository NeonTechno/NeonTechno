# ASCII profile artwork checks

This directory contains validation and tests for the animated SVG environments embedded directly in the GitHub profile README.

The profile artwork lives at the repository root:
- `nature-ascii.svg` — moonlit rainforest and waterfall
- `space-ascii.svg` — deep-field galaxy and orbital scene
- `cyber-city-ascii.svg` — neon city and elevated transit

There is no standalone preview website and no GitHub Pages deployment. The SVG files are the profile artwork.

## Validate

Run `npm run check` and `npm test` from this directory.
